# HotelPro — Frontend Client

Modern React 19 web application built with Vite, Tailwind CSS, Lucide icons, and Motion.

## Features
- Real-time room availability & interactive date-range booking
- Deluxe and Executive room catalog with gallery views and filters
- Guest reservation manager with instant cancellation & confirmation receipts
- Administrator dashboard with live room & user management
- Integrated proxy to the backend API (`/api` -> `http://localhost:5000`)
- Built-in offline fallback with local state persistence

## Scripts
```bash
# Install dependencies
npm install

# Start Vite dev server on http://localhost:5173
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
